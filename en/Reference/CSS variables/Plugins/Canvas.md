This page lists CSS variables used by the [Canvas](https://help.obsidian.md/Plugins/Canvas) plugin.

## CSS variables

| Variable                    | Description                  |
| --------------------------- | ---------------------------- |
| `--canvas-background`       | Canvas background color      |
| `--canvas-card-label-color` | Canvas card label text color |
| `--canvas-dot-pattern`      | Canvas dot pattern color     |
| `--canvas-color-1`          | Canvas card color 1, red by default    |
| `--canvas-color-2`          | Canvas card color 2, orange by default |
| `--canvas-color-3`          | Canvas card color 3, yellow by default |
| `--canvas-color-4`          | Canvas card color 4, green by default  |
| `--canvas-color-5`          | Canvas card color 5, cyan by default   |
| `--canvas-color-6`          | Canvas card color 6, purple by default |
