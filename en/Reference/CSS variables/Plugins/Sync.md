This page lists CSS variables used by the [Sync](https://help.obsidian.md/Obsidian+Sync) plugin.

## CSS variables

| Variable                           | Description                   |
| ---------------------------------- | ----------------------------- |
| `--sync-avatar-color-current-user` | Avatar color for current user |
| `--sync-avatar-color-1`            | Avatar color 1, red by default    |
| `--sync-avatar-color-2`            | Avatar color 2, orange by default |
| `--sync-avatar-color-3`            | Avatar color 3, yellow by default |
| `--sync-avatar-color-4`            | Avatar color 4, green by default  |
| `--sync-avatar-color-5`            | Avatar color 5, cyan by default   |
| `--sync-avatar-color-6`            | Avatar color 6, blue by default   |
| `--sync-avatar-color-7`            | Avatar color 7, purple by default |
| `--sync-avatar-color-8`            | Avatar color 8, pink by default   |
